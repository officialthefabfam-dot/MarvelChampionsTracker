# Marvel Champions Tracker

A standalone iOS companion app for tracking heroes, villains, decks, campaigns, collection ownership, and play statistics.

## Design direction

- Light, premium command-centre interface
- Warm ivory and light-grey surfaces with navy text
- Subtle red and blue accents; gold for achievements
- Offline-first local storage with backup and restore
- Original interface elements; no copied Marvel logos or card artwork

## Development

The app will be built with SwiftUI for iOS 17 and later. The initial milestone is the native app foundation and a reliable unsigned iOS build workflow.
